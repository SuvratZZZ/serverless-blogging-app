# Serverless Blogging App

A modern, full-stack serverless blogging platform designed for scalability, cost efficiency, and ease of deployment. This project leverages a serverless architecture to provide a seamless blogging experience, with both frontend and backend components managed independently for maximum flexibility.

---

**Live Demo:** serverless-blogging-app-amber.vercel.app

---

## Features

- Create, read, update, and delete blog posts
- User authentication and authorization
- Responsive and modern UI
- Serverless backend for high scalability and low maintenance
- Fast and secure content delivery

---

| Layer      | Technologies Used                       |
|------------|----------------------------------------|
| Frontend   | TypeScript, JavaScript, HTML, CSS      |
| Backend    | TypeScript (likely Node.js)            |
